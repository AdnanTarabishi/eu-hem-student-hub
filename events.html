Publishing principles

Clear details. Visible changes.

The future event collection will build on the Hub's existing Calendar and prepared editorial workflow.

  1. Review the source.Check the organiser's announcement, audience, schedule and registration details before publication.
  2. Publish one consistent record.The event page and Calendar will use the same reviewed information, with explicit local time zones.
  3. Keep changes visible.Postponements, cancellations and missing details will be labelled clearly; visitors should check the original source before travelling.
  4. Link the follow-up.Add approved recaps or Gallery albums after an event, with contributor credit and the appropriate audience.

Participation features come later.

Event submissions and attendance responses are planned. This preview does not accept registrations, collect attendee details or activate event publishing.
