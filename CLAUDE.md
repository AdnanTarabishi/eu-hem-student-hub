# EU-HEM Student Hub
Unofficial, free, volunteer website for students of the EU-HEM master's program (University of Bologna and partner universities).

## Users
- About 100 students in semester 1. In semester 2 they split into 4 tracks at different universities.
- Should stay useful for future cohorts.

## Phase 1 (now): public information site, no login
- Schedules, important dates and exams
- Student notes, summaries and supporting resources
- Useful links and practical info for students
- Official lectures stay on Virtuale (UniBo) and must NOT be re-uploaded here. Link to Virtuale instead.
- Do not publish students' personal data (phone numbers, emails) on the public site.

## Later
- Student accounts and login, content per track.

## Long-term vision
See docs/vision.md. We are currently in Phase 1. Build new features so they fit the vision (for example, structure data so it can support multiple cohorts and a future login), but do not build ahead of the current phase. Ask me before any Phase 2 technology decision.

## Tech
- Start simple: HTML, CSS, JavaScript. No frameworks until really needed.
- Hosted on GitHub Pages (GitHub user: AdnanTarabishi).
- Interface in English. Mobile-friendly.
- This is a learning project: keep code readable and explain choices.
